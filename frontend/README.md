# PskHome Frontend

Next.js (App Router) + TypeScript 프론트엔드.

개발 가이드는 [`CLAUDE.md`](CLAUDE.md), 프로젝트 전체 개요는 [`../docs/skill.md`](../docs/skill.md) 참고.

```bash
# 개발 서버 (localhost:5173, /api → localhost:8080 프록시)
npm install
npm run dev

# 프로덕션 빌드 (standalone 출력)
npm run build
npm run start

# 검증
npm run lint
npm run test
```
